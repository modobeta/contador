# Contador Simple

Una aplicación web simple de contador construida con HTML, CSS y JavaScript.

## Funcionalidades

- Incrementar el contador con el botón **+**
- Decrementar el contador con el botón **-**
- Reiniciar el contador a 0 con el botón **Reset**
- Cambio de color dinámico: verde para positivos, rojo para negativos, gris para cero

## Demo en producción

[https://modobeta.github.io/contador/](https://modobeta.github.io/contador/)

## Cómo usar

Abre el archivo `index.html` en cualquier navegador web moderno.
